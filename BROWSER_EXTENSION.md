# ND Launcher browser extension

[English](BROWSER_EXTENSION.md) · [Русский](BROWSER_EXTENSION.ru.md) · [中文](BROWSER_EXTENSION.zh-CN.md)

The extension hands model downloads from Hugging Face, Civitai.com, Civitai.red and ModelScope.cn to ND Launcher. It supports three languages and three themes, It is an official extension for Chromium-based browsers (Chrome, Edge, Yandex Browser, Brave, Vivaldi and others), published in the [Chrome Web Store](https://chromewebstore.google.com/detail/ikiegihpjhkejmbbbdiiombnaihannca).

[Installation and usage](chrome_extension/INSTALL.md).
