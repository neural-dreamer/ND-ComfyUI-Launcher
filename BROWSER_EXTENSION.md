# ND Launcher browser extension

[English](BROWSER_EXTENSION.md) · [Русский](BROWSER_EXTENSION.ru.md) · [中文](BROWSER_EXTENSION.zh-CN.md)

The extension hands model downloads from Hugging Face, Civitai.com, Civitai.red and ModelScope.cn to ND Launcher. It supports three languages and three themes, with setup for supported Chromium browsers.

[Installation and usage](chrome_extension/INSTALL.md).
