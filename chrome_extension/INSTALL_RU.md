# Расширение браузера ND Launcher

[English](INSTALL.md) · [Русский](INSTALL_RU.md) · [中文](INSTALL.zh-CN.md)

Расширение передаёт загрузки моделей с **Hugging Face, Civitai.com, Civitai.red и ModelScope.cn** в ND Launcher, сохраняя выбранную в браузере папку назначения. Для приёма загрузок лаунчер должен быть запущен; запускать сам ComfyUI не обязательно.

## Установка и подключение

1. В лаунчере открой **Настройки → Загрузки из браузера → Установить расширение браузера**.
2. Выбери обнаруженный браузер или укажи portable-браузер через **Обзор…**. Этот выбор сохраняется отдельно от браузера для ComfyUI.
3. Нажми **«Подготовить и открыть папку»**. Лаунчер подготовит постоянную папку и выделит её в Проводнике; путь также появится в диалоге и буфере обмена.
4. Самостоятельно открой страницу расширений выбранного браузера. Включи режим разработчика и выбери **«Загрузить распакованное расширение»**, указав подготовленную папку. Если браузер поддерживает установку перетаскиванием, можно перетащить папку на эту страницу.
5. В лаунчере включи приём моделей из браузера и скопируй ключ подключения.
6. Открой расширение, разверни **«Подключение»**, вставь ключ, нажми **«Сохранить»**, затем **«Проверить связь»**. Включи тумблер перехвата.
7. В настройках скачивания браузера включи запрос места сохранения, чтобы выбирать папку при скачивании модели.

| Браузер | Страница расширений |
|---|---|
| Chrome / Chromium / Thorium | `chrome://extensions/` |
| Yandex Browser | `browser://extensions/` |
| Microsoft Edge | `edge://extensions/` |
| Brave | `brave://extensions/` |
| Opera / Opera GX | `opera://extensions/` |
| Vivaldi | `vivaldi://extensions/` |

Помощник рассчитан на перечисленные Chromium-браузеры. Firefox не поддерживается. Завершающий шаг установки выполняется вручную; права администратора не нужны.

Альтернативная подготовка: запусти [INSTALL_BROWSER.bat](INSTALL_BROWSER.bat). Он предлагает выбор браузера, готовит папку и открывает браузер. Python для этого помощника не нужен. Для самих загрузок работающий лаунчер всё равно необходим.

## Интерфейс

- Язык выбирается справа вверху: **РУ / EN / 中文**.
- Крупный тумблер включает и выключает перехват; изменение сохраняется сразу.
- **«Подключение»** и **«Как начать»** свёрнуты по умолчанию.
- Цветные капсулы снизу выбирают **Неон / Туманная ночь / Классик**. Тема и язык сохраняются в профиле браузера. Логотип и значок на панели браузера меняют цвета; значок на странице управления расширениями остаётся исходным.

## Обновление

Повтори подготовку расширения из новой версии лаунчера, затем нажми **«Обновить»** на карточке расширения в каждом браузере, где оно установлено. Постоянная папка: `%LOCALAPPDATA%\NDLauncher\ChromeExtension`; не удаляй её. Файлы общие, настройки относятся к профилю браузера. Если расширение установлено напрямую из `chrome_extension`, обнови файлы именно в той папке.

## Поддержка загрузок

Форматы: `.safetensors`, `.ckpt`, `.pt`, `.pth`, `.bin`, `.gguf`, `.zip`. Перехват использует исходную ссылку или источник загрузки для определения сайта и работает с локальным путём Windows. Инкогнито не поддерживается.

Для закрытых моделей Hugging Face и Civitai могут понадобиться API-токены в лаунчере. Cookies браузера не передаются. ModelScope поддерживается для публичных файлов и доступных подписанных ссылок. Если лаунчер недоступен до передачи задания, скачивание остаётся в браузере. Для ожидающих передач есть кнопка **«Повторить передачу»** в блоке подключения.
