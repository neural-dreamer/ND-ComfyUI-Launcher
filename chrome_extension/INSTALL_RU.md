# Расширение браузера ND Launcher

[English](INSTALL.md) · [Русский](INSTALL_RU.md) · [中文](INSTALL.zh-CN.md)

Расширение передаёт загрузки моделей с **Hugging Face, Civitai.com, Civitai.red и ModelScope.cn** в ND Launcher, сохраняя выбранную в браузере папку назначения. Для приёма загрузок лаунчер должен быть запущен; запускать сам ComfyUI не обязательно.

## Установка и подключение

Расширение опубликовано в [Chrome Web Store](https://chromewebstore.google.com/detail/ikiegihpjhkejmbbbdiiombnaihannca).

1. В лаунчере открой **Настройки → Загрузки из браузера → Установить расширение браузера**.
2. Выбери обнаруженный браузер или укажи portable-браузер через **Обзор…**. Этот выбор сохраняется отдельно от браузера для ComfyUI.
3. Нажми **«Открыть страницу в Chrome Web Store»**. Лаунчер откроет страницу расширения в этом браузере; нажми **«Установить»**. Страницу можно открыть и самостоятельно в любом Chromium-браузере ([ссылка](https://chromewebstore.google.com/detail/ikiegihpjhkejmbbbdiiombnaihannca)) или воспользоваться кнопкой **«Скопировать ссылку»**.
4. В лаунчере включи приём моделей из браузера и скопируй ключ подключения.
5. Открой расширение, разверни **«Подключение»**, вставь ключ, нажми **«Сохранить»**, затем **«Проверить связь»**. Включи тумблер перехвата.
6. В настройках скачивания браузера включи запрос места сохранения, чтобы выбирать папку при скачивании модели.

Opera сама не ставит расширения из Chrome Web Store: сначала добавь в неё дополнение «Install Chrome Extensions». Firefox не поддерживается.

### Ручная установка (запасной вариант)

Если магазин недоступен, нажми **«Установить вручную из папки»** в том же диалоге. Лаунчер подготовит постоянную папку и выделит её в Проводнике. Открой страницу расширений браузера, включи режим разработчика, выбери **«Загрузить распакованное расширение»** и укажи эту папку. Можно также запустить [INSTALL_BROWSER.bat](INSTALL_BROWSER.bat). Некоторые браузеры, например Яндекс Браузер, отключают распакованные расширения при каждом запуске, поэтому лучше ставить версию из магазина.

| Браузер | Страница расширений |
|---|---|
| Chrome / Chromium / Thorium | `chrome://extensions/` |
| Yandex Browser | `browser://extensions/` |
| Microsoft Edge | `edge://extensions/` |
| Brave | `brave://extensions/` |
| Opera / Opera GX | `opera://extensions/` |
| Vivaldi | `vivaldi://extensions/` |

Лаунчер умеет открывать страницу магазина в перечисленных Chromium-браузерах. Права администратора не нужны. Для самих загрузок работающий лаунчер всё равно необходим.

## Интерфейс

- Язык выбирается справа вверху: **РУ / EN / 中文**.
- Крупный тумблер включает и выключает перехват; изменение сохраняется сразу.
- **«Подключение»** и **«Как начать»** свёрнуты по умолчанию.
- Цветные капсулы снизу выбирают **Неон / Туманная ночь / Классик**. Тема и язык сохраняются в профиле браузера. Логотип и значок на панели браузера меняют цвета; значок на странице управления расширениями остаётся исходным.

## Обновление

Версия из магазина обновляется автоматически. Если расширение установлено вручную, повтори подготовку расширения из новой версии лаунчера, затем нажми **«Обновить»** на карточке расширения в каждом браузере, где оно установлено. Постоянная папка: `%LOCALAPPDATA%\NDLauncher\ChromeExtension`; не удаляй её. Файлы общие, настройки относятся к профилю браузера. Если расширение установлено напрямую из `chrome_extension`, обнови файлы именно в той папке.

## Поддержка загрузок

Форматы: `.safetensors`, `.ckpt`, `.pt`, `.pth`, `.bin`, `.gguf`, `.zip`. Перехват использует исходную ссылку или источник загрузки для определения сайта и работает с локальным путём Windows. Инкогнито не поддерживается.

Для закрытых моделей Hugging Face и Civitai могут понадобиться API-токены в лаунчере. Cookies браузера не передаются. ModelScope поддерживается для публичных файлов и доступных подписанных ссылок. Если лаунчер недоступен до передачи задания, скачивание остаётся в браузере. Для ожидающих передач есть кнопка **«Повторить передачу»** в блоке подключения.
