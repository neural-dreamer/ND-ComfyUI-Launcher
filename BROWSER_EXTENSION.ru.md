# Расширение браузера ND Launcher

[English](BROWSER_EXTENSION.md) · [Русский](BROWSER_EXTENSION.ru.md) · [中文](BROWSER_EXTENSION.zh-CN.md)

Расширение передаёт загрузки моделей с Hugging Face, Civitai.com, Civitai.red и ModelScope.cn в ND Launcher. Доступны три языка, три темы Это официальное расширение для браузеров на основе Chromium (Chrome, Edge, Яндекс Браузер, Brave, Vivaldi и другие), оно опубликовано в [Chrome Web Store](https://chromewebstore.google.com/detail/ikiegihpjhkejmbbbdiiombnaihannca).
