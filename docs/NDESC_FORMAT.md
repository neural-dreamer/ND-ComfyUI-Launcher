# Формат описаний воркфлоу `.ndesc` (версия 1)

Описания воркфлоу для вкладки «Воркфлоу» в ND Launcher.

## Где лежит

```
ComfyUI_windows_portable\
├── ComfyUI\user\default\workflows\   ← сами воркфлоу (.json)
├── python_embeded\
└── utils\
    ├── workflows.ndesc                ← описания
    └── previews\flux_txt2img.png      ← картинки-превью (необязательно)
```

- Лаунчер читает **все** файлы `utils\*.ndesc` и `utils\*.ndesc.json` и объединяет их (второе расширение — для файлов из генератора NDesc Studio; содержимое одинаковое). Можно держать один большой файл или несколько (например, `base.ndesc` + `video.ndesc` для отдельного пака). Если один воркфлоу описан в двух файлах, побеждает файл, идущий позже по алфавиту.
- Если ни одного `.ndesc` нет, справа показывается «Описания воркфлоу не найдены.».
- Файл с ошибкой пропускается, а причина пишется в консоль лаунчера.

## Синтаксис

Это обычный **JSON в кодировке UTF-8**. Расширение `.ndesc` нужно, чтобы файл не путали с воркфлоу. Комментарии JSON не поддерживает.

```json
{
  "format": "ndesc",
  "version": 1,
  "build": {
    "name": "Сборка ND",
    "version": "2026.10",
    "author": "ND",
    "url": "https://boosty.to/..."
  },
  "workflows": {
    "<путь к воркфлоу>": { ...описание... }
  }
}
```

| Поле | Обязательное | Что это |
|---|---|---|
| `format` | да | Всегда строка `"ndesc"`: по ней лаунчер узнаёт файл |
| `version` | да | Версия формата, сейчас `1` |
| `build` | нет | Информация о сборке, сейчас только справочная |
| `workflows` | да | Объект: ключ — путь к воркфлоу, значение — описание |

### Ключ воркфлоу

Путь к `.json` **относительно папки `ComfyUI/user/default/workflows`**, через прямой слэш:

- `"txt2img_flux.json"` — файл в корне папки воркфлоу;
- `"Video/wan_i2v.json"` — файл в подпапке `Video`.

Регистр букв не важен. Если файл переместили в другую подпапку, лаунчер найдёт описание по одному имени файла. Поэтому имена воркфлоу лучше держать уникальными.

## Поля описания

Все поля необязательные. Чем больше заполнено, тем богаче карточка.

| Поле | Тип | Как показывается |
|---|---|---|
| `title` | строка | Понятное название для поиска. В списке и в заголовке карточки лаунчер всегда показывает **имя файла** воркфлоу (без `.json`), `title` их не подменяет |
| `short` | строка | Одна строка-подзаголовок курсивом: что делает воркфлоу в двух словах |
| `category` | строка | Категория рядом с заголовком: «Генерация», «Видео», «Апскейл»… |
| `tags` | массив строк | Теги `#flux #lora`; по ним работает поиск |
| `preview` | строка | Картинка: путь относительно папки `utils` (`"previews/flux.png"`) или абсолютный |
| `description` | строка или массив строк | Основной текст, **Markdown**: абзацы, `**жирный**`, списки, ссылки. Массив строк склеивается переводами строк — так длинный текст удобнее писать в JSON |
| `steps` | массив строк | Нумерованный список «Как пользоваться» |
| `models` | массив | Нужные модели (см. ниже). Лаунчер сам проверяет, лежат ли они в сборке, и ставит ✓ или ✗ |
| `custom_nodes` | массив | Нужные кастом-ноды (см. ниже), тоже с проверкой ✓ / ✗ |
| `vram` | строка | Требования к видеопамяти: `"12 ГБ+"`, `"8 ГБ с fp8"` |
| `time` | строка | Примерное время генерации: `"~40 с на RTX 4070 Ti"` |
| `video` | строка (URL) | Ссылка «▶ Видео-разбор» |
| `links` | массив `{title, url}` | Дополнительные ссылки |
| `version` | строка | Версия воркфлоу (в подвале карточки) |
| `updated` | строка | Дата обновления, лучше `ГГГГ-ММ-ДД` |
| `author` | строка | Автор |

### `models`

Каждый элемент — объект или просто строка с именем:

```json
{ "name": "flux1-dev-fp8.safetensors", "folder": "diffusion_models", "size": "11.9 ГБ", "url": "https://huggingface.co/...", "note": "можно заменить на GGUF" }
```

- `name` — имя файла модели. Можно с подпапкой: `"flux/flux1-dev.safetensors"`.
- `folder` — папка внутри `ComfyUI/models`: `checkpoints`, `diffusion_models`, `loras`, `vae`, `text_encoders`, `clip_vision`, `controlnet`, `upscale_models` и т.д. Без `folder` проверка наличия не выполняется.
- `size`, `url`, `note` — необязательные.

Наличие проверяется по точному пути, а если его нет — по имени файла в любой подпапке `folder`.

### `custom_nodes`

Строка с именем папки ноды или объект:

```json
{ "name": "ComfyUI-KJNodes", "url": "https://github.com/kijai/ComfyUI-KJNodes" }
```

`name` должно совпадать с именем папки в `ComfyUI/custom_nodes` (регистр не важен, отключённые `.disabled` тоже считаются установленными).

## Альтернативная запись

Вместо объекта `workflows` можно использовать массив, где путь лежит в поле `file`:

```json
"workflows": [
  { "file": "txt2img_flux.json", "title": "..." }
]
```

## Правила, чтобы ничего не сломалось

1. Внутри строк кавычки экранируются: `\"`. Перевод строки в тексте — `\n` (или используй массив строк в `description`).
2. Обратные слэши в путях Windows лучше не использовать — пиши `previews/flux.png`.
3. После правки можно нажать «↻ Обновить» на вкладке «Воркфлоу», перезапускать лаунчер не нужно.
4. Если появятся новые поля, в будущей версии формата `version` станет `2`. Лаунчер v1 прочитает такой файл и просто проигнорирует незнакомые поля.

Полный рабочий пример — `utils/workflows.ndesc.example`. Чтобы включить его, переименуй в `workflows.ndesc`.
