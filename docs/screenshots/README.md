# Скриншоты для README

README ссылается на три картинки — положи их сюда с этими именами (PNG, ширина ~1200–1400 px, тема «Неон»):

| Файл | Что на нём |
|---|---|
| `launch.png` | Вкладка «Запуск» целиком (главный скриншот наверху README) |
| `transfer.png` | Вкладка «Перенос» с выбранной старой сборкой и списком кастом-нод (недостающие подсвечены) |
| `models.png` | Вкладка «Загрузка моделей» с найденными файлами и плашкой свободного места |

Язык интерфейса на скриншотах — английский (EN), так README понятнее всем. Токены в поле API перед съёмкой скрой (блок по умолчанию свёрнут).
